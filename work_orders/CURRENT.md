# Current work boundary

The scientific contribution is frozen: the exact real, single-copy,
universally unbiased readout limit, its sparse attaining measurement, and
existing charged circuit realizations. See [Scope](../docs/SCOPE.md) and
[the evidence index](../docs/EVIDENCE.md).

The current engineering task consolidates documentation, supported code,
reproducibility, and the GitHub reader experience. It permits a reviewed merge
into main once safety, evidence preservation, functionality, and presentation
checks pass. It does not dispatch another scientific study.

Completed scientific packets remain evidence, not executable instructions to
repeat their original work orders. Historical scope and working instructions
are preserved in [the migration record](../maintenance/repository-polish/REPORT.md).

Stop after the self-contained repository is validated and integrated. Manuscript
preparation is the last, separately authorized step. No tag, release, DOI,
registry publication, or researcher contact is part of this task.
