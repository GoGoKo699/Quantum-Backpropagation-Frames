# PF-01 matched-cost audit

Machine-readable formulas, qualifications, and illustrative substitutions are in `resource_table.json`, generated by `resources.py`. The imported source tables are not overwritten or treated as optimality certificates.

## 1. One output and access contract

Every eligible procedure returns all P raw real gradient entries with Pr(||g_hat-g||_2<=epsilon)>=1-delta. All receive the same fresh reference-response preparation with phase-calibrated controlled objective, T, and the same valid local tangent representation when locality is assumed. One record requires another response preparation; classical reuse across indices is not quantum-state reuse across shots.

For a bound B on total single-record variance, compare K=ceil(B/(delta epsilon^2)) for the unchanged unbiased sample mean. This common sufficient prescription is intentionally conservative. It is not the exact optimal sample complexity of a method. Near-optimal frame slack eta is different from gradient error epsilon.

Preprocessing, sampling/synthesis randomness, work ancillas, measurement and reset, objective calls, basis-change gates, record processing, final decoding, and P output writes are separate ledger entries. All-to-all logical gates are not routed depth or wall-clock time.

## 2. The comparison set

| Method | Total-variance upper bound | Readout resources beyond common preparation |

| No mask | 2s(1+beta) | Product X readout; no added two-qubit gates |

| Same full mask, optimized | 4s | Allow optimized Clifford synthesis and terminal relabeling; do not impose direct-CZ cost |
| k clean parity rounds | 4s+2s(beta-1)4^(-k) | Expected 2nk CNOT+k CZ; two clean work qubits |

S1-S9 in SOURCE_AUDIT.md identify the source relationships. The local block comparator uses the same reference-specific low-rank targets as the imported matched packet. It already has O(s/epsilon^2) whole-vector scaling, and O(nw) direct block gates, so a parity O(nw) bound is not an asymptotic improvement over every local scheme.

## 3. Terminal uncomputation must be allowed when the task ends in measurement

Measuring each parity work qubit in X after the CZ gives outcomes u,v. The induced Kraus map on the system is one half of the desired diagonal phase times the known character labeled u a+v b. Shift the final X outcome by this label. Summing over work outcomes reproduces the clean-gadget distribution exactly, including the reference ancilla.

This halves the displayed expected CNOT count, but adds measurement/reset latency and changes the interface. It cannot replace a block whose downstream use requires two coherent clean work qubits. It is an eligible final-readout implementation under a measurement-enabled contract. Its justification and independent probability tests are in PROOF_AUDIT.md and audit.py. It uses a known terminal-gate-to-postprocessing principle, not a new measurement primitive.

## 4. Classical decoding: no intentionally inefficient comparator

For parity, the packet supplies the valid direct-record bound

```math
O(nk+\sum_j\min\{4^k,kw_j^2+w_j2^{w_j}\}).
```

It is not a minimum. Repeated shifts, shared support intervals, aggregation, and preprocessing may improve it. The same latitude applies to every shadow method. Block snapshots need only the relevant zero-column entries, not complete density matrices. Global stabilizer amplitudes need only be evaluated on the union of target supports. Full response tomography is not forced on a comparator when it only needs the specified linear functionals.

Computing beta is not free. Interval supports permit boundary-state dynamic programming polynomial in the number of local tables and exponential in their maximum width. Generic dense T does not inherit that efficiency. Local table construction, parameter precision, bit-parity cost beyond a machine word, and recomputation when the parameter point changes must all be counted.

## 5. Exact crossover for the displayed sufficient prescriptions

Let C denote common response cost plus any common per-record cost. Let R_k and R_f be the remaining per-record costs of a finite-round compiler and a full-mask implementation, in explicitly chosen units. Ignoring common confidence/accuracy factors and integer rounding, write

```math
A_k=B_k/(4s)=1+(\beta-1)/(2\,4^k).
```

Parity is cheaper than that full-mask implementation precisely when

```math
(A_k-1)C < R_f-A_kR_k.
```

When the right side is positive, the crossover is C=(R_f-A_k R_k)/(A_k-1). Thus very expensive response preparation favors the lower-variance full mask against a FIXED finite k, unless k is increased or an instance-specific variance calculation changes the comparison. There is no general rule that expensive objectives always favor finite-round parity against every alternative.

Against no mask, increased C can favor parity because parity reduces the no-mask variance bound. If beta=1, no mask already reaches 4s and extra randomization cannot improve that bound; added gates are not justified by it.

For n=1024, w=6, beta<=64 and eta=0.1, k=5 gives B_k/(4s)=1.03076171875. Direct full masking uses 261888 expected CZ. Clean parity uses 10240 expected CNOT+5 CZ. Measured-uncompute parity uses 5120 expected CNOT+5 CZ plus ten measurements and ten resets.

With equal unit prices for CNOT and CZ, zero prices for classical work and terminal measurement/reset, and no preprocessing price, the respective crossover C values are approximately 8.17015 million and 8.34171 million gate units. These are analytical gate-only illustrations, not total-runtime bounds. Pricing resets, routing, or classical operations changes them. Allowing optimized full-mask synthesis changes them. Optimizing k changes them. The JSON deliberately labels these restrictions.

## 6. Why the audit does not establish the final advantage goal

The parity construction has a correct gate/covariance trade-off relative to the direct dense implementation. It can approach the frame-class 4s endpoint with O(n(w+log(1/eta))) expected clean parity CNOTs for width w.

A general optimized Clifford circuit need not have a quadratic gate floor. Conversely a near-linear two-design cannot simply be awarded the Clifford third-moment variance. Shallow-shadow target bounds and local-block schemes must be evaluated, not dismissed or given unsupported guarantees. The currently supplied packet lacks a compiled, same-task, complete finite-cost comparison against all these eligible alternatives.

Global Clifford and local block constructions already attain the same whole-vector sample scaling in their applicable regimes. No quantum-hard objective or measured hardware runtime is supplied. The rank witness is a phase-rank lower bound, not a gate lower bound against those alternatives. Consequently the ultimate end-to-end improvement goal remains OPEN.

The meaningful retained result is a supported restricted covariance/compiler theorem with a parameterized cost decision, not a universal optimal gradient algorithm.
