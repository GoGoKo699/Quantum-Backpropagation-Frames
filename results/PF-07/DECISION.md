# PF-07 decision

ACCEPT the overlapping-interval known-reference compiler as a constructive,
reproducible extension of PF-06. It recovers the previously missed overlapping-
layer gradient and requires no supplied eigenbasis, global support union or
quantum data-access oracle. The exact logical row-norm measurement is globally
unbiased and has trace risk at most 4 tr(G), using one reference-response copy.

DO NOT extend the flat-spectrum exact optimum to arbitrary coordinate-row
supports. A null response inside that support can saturate 4 tr(G). The new
bound is within the inherited factor-two statistical bracket, not a new exact
anisotropic optimum. Trace-risk and individual-coordinate/infinity-norm
performance remain different contracts.

The elementary compiler is O(n2^w); source tables, program storage/regeneration,
bit acquisition, local sparse updates and original P-vector output are charged.
The auxiliary fixed-envelope dimension argument only concerns exact reference
state preparation in a declared gate model. It does not establish a lower
bound for all gradient readouts or all circuit-derived references.

No new strongest-baseline total-work advantage is established. The streamed
classical decoder is cheaper than reconstructing many record moments, but its
reference circuit may cost more. Optimized state preparation, masks, grouped
reversed tests and aggregate-first shadows remain eligible on the same data.
Prior parity-negative evidence stays intact. No favorable-price search is run.

The next scientific decision should focus on the remaining implementation-cost
tradeoff, not repeat the same proof audit or treat overlap as an impossibility.
This packet supplies the general bounded-width construction needed for that
comparison. It does not authorize another work order, integration, manuscript,
release or license. Stop with the code, proof, evidence and bounded conclusion.
