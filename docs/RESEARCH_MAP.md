# Scientific map

Start with the [physical problem and example](TUTORIAL.md). The complete gradient
is a vector of signed overlaps with known tangent directions. Reference
interference turns those signs into measurable outcome biases.

The [all-measurement theorem](THEORY.md) fixes the least possible worst-response
variance for equal nonzero tangent sensitivities. Its sparse attaining POVM
settles the statistical question, but an abstract tangent-basis isometry is not
automatically a cheap circuit.

The [constructive circuits](COMPILERS.md) address implementation separately.
A disjoint local family attains the theorem. Overlapping intervals support
row-norm reference preparation with bounded risk and explicit width-dependent
cost. Coordinate support can exceed tangent span.

[Comparisons](COMPARISONS.md) keeps eligible alternatives and negative evidence
visible. Reducing variance, settings, or streaming arithmetic alone does not
establish reduced total work. The [evidence index](EVIDENCE.md) maps the argument
to proofs, code, tests, fixed data, and limitations.
